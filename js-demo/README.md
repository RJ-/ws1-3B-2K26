# WS1 Week 11 · JavaScript Code-Along Starters

1. Open this folder in VS Code.
2. Right-click `index.html` → **Open with Live Server**. It links to all four projects.
3. Press **F12** and keep the **Console** tab open the whole time.
4. Type your code in each project's `script.js`, under the TODO comments.

| # | Folder | What we do |
|---|---|---|
| 1 | `dom-playground/` | Lecture warm-up: the DOM, finding elements, textContent vs innerHTML |
| 2 | `bucket-list/` | Change, add, and remove list items; swap an image; toggle a class |
| 3 | `party-colors/` | Click to paint the page a random color (and find a hidden bug) |
| 4 | `portfolio-lab/` | Sample portfolio for the Week 11 lab, **only if your own portfolio isn't working** |

**Fell behind?** Copy the step you're on from `checkpoints/` (for example
`checkpoints/bucket-list/step3-script.js`) over your `script.js` and keep going.

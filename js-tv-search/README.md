# WS1 · Palabas TV Show Search Code-Along (TVmaze API)

1. Open this folder in VS Code. Right-click `index.html` → **Open with Live Server**.
2. Press **F12** and keep the **Console** and **Network** tabs open.
3. Type your code in `script.js`, under the TODO comments. `CodeAlong_Guide.md` has every step.

**No API key needed.** TVmaze is free.

**Sample mode** (default in `config.js`) works offline. Try: `friends`, `office`, `breaking bad`,
`stranger things`, `sherlock`, `thrones`, or `sample` for all six.

**Live mode:** set `USE_SAMPLE_DATA = false` in `config.js`. TVmaze allows about 20 requests every
10 seconds per internet connection, so in the lab stay in sample mode until your teacher says to switch.

**Fell behind?** Copy the step you're on from `checkpoints/` (e.g. `checkpoints/step3-script.js`) over your `script.js`.

What you'll build

Palabas searches the free TVmaze API. Type a show's title and you get a grid of poster cards. Click a card and a pop-up shows the summary, cast, and number of seasons, loaded with three requests at once.

You'll practice everything from the async unit: fetch, async/await, try/catch, response.ok, handling errors, and Promise.all.

Rules for this assignment

  • Type your own code. Read the task, try it first, then open Hint 1, then Hint 2. Open Hint 3 only when you've been stuck for 20 minutes.
  • Explain every function. Above each function you write, add a comment in your own words saying what it does. This is graded.
  • AI tools: if you use an AI assistant, say in your reflection what you asked it and what you changed. Don't paste code you can't explain.
  • Ask early. Post questions in the Classroom stream with a screenshot of your Console. Helping a classmate is welcome too.

Get the starter files

10 min

  • 2Open the folder in VS Code. Right-click index.html → Open with Live Server. Open DevTools (F12): Console and Network.
  • 3Read the top of script.js. The URL functions (searchURL, showURL, castURL, seasonsURL) and helpers (el, setStatus, createPoster, yearRange, stripTags) are given. You will use them, not change them.
  • 4Read config.js. Start in sample mode (USE_SAMPLE_DATA = true): it works offline with friends, office, breaking bad, stranger things, sherlock, thrones, or sample for all six.

Live mode (USE_SAMPLE_DATA = false) searches every show on TVmaze, with no key needed. TVmaze allows about 20 requests every 10 seconds per internet connection. Use live mode at home or on your own mobile data, not on shared lab Wi-Fi. Your final app must work in both modes.

Hint 1 · The idea

Promise.all([p1, p2, p3]) waits for all three and gives back an array of results in the same order. Unpack it with array destructuring: const [show, cast, seasons] = await Promise.all([...]). The cast is an array of { person, character }; use cast.slice(0, 6).

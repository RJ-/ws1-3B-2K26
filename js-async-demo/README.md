# WS1 Week 12 · Async JavaScript Code-Along Starters

1. Open this folder in VS Code.
2. Right-click `index.html` → **Open with Live Server**. It links to all four projects.
   (`fetch()` does not work if you open a page by double-clicking it.)
3. Press **F12** and keep the **Console** tab open the whole time.
4. Type your code in each project's `script.js`, under the TODO comments.
5. `CodeAlong_Guide.md` has the code for every step, plus the lab tasks.

| # | Folder | What we do |
|---|---|---|
| 1 | `async-warmup/` | Predict the order of `setTimeout`, freeze the page on purpose, build a clock |
| 2 | `kape-orders/` | One coffee order four ways: callbacks → Promises → `.then()` → `async`/`await`, then `Promise.all` |
| 3 | `fetch-explorer/` | Load `data/events.json` with `fetch()`, then search the PokéAPI |
| 4 | `portfolio-lab/` | Sample portfolio for the Week 12 lab, **only if your own portfolio isn't working** |

**Fell behind?** Copy the step you're on from `checkpoints/` (for example
`checkpoints/kape-orders/step3-script.js`) over your `script.js` and keep going.
